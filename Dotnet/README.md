# BluetoothWebApp

## Run
Start MQTT broker
- NOTE: requires Dotnet core 8+
```
cd TestMqttBroker
dotnet run
```
Start Bluetooth web app
- NOTE: requires Dotnet core 8+
```
cd BluetoothWebApp
dotnet run
```
Start Zed app
- NOTE: requires Dotnet framework v4.8.1
- NOTE: tested on Zed SDK v4
```
cd ZedConsoleApp
dotnet run
```
